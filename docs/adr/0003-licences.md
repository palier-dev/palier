# ADR 0003: Licences

- **Status:** Accepted
- **Date:** 2026-10-23

## Decision
- Code: **Apache-2.0** (`LICENSE`)
- Documentation and synthetic dataset: **CC BY 4.0** (`docs/LICENSE`)

## Rationale
Apache-2.0 is permissive and includes an explicit patent grant. CC BY 4.0 lets anyone reuse the docs and dataset with attribution, matching the project's educational goal.

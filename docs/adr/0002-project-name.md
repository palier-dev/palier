# ADR 0002: Project name "Palier"

- **Status:** Accepted
- **Date:** 2026-10-23

## Context
Need a short, lowercase, accent-free name usable as domain, GitHub repo, Kubernetes namespace and package name, meaningful in the domain and not already a proptech brand.

## Decision
**palier**: the landing where neighbours meet, and a step climbed one at a time. Domain `palier.dev` registered at Cloudflare (2 years).

## Consequences
GitHub organization: **palier-dev** (`palier` was taken). It mirrors the domain and states the audience: developers, including vibe coders.

Identifiers: repo `palier-dev/palier`, namespace `palier`, sub-components `palier-<name>` (e.g. `palier-mcp`, `palier-docs`).
